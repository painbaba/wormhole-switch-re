Wormhole Switch Architecture

J5Create Wormhole USB A↔A Bridge Cable (VID 0711 / PID 2211)

USB Topology

  • • PC A ↔ USB A ↔ Cable ↔ USB A ↔ PC B
  • • Single compound device per host (3 interfaces)
  • • Identical enumeration regardless of peer connection
  • • Peer link internal to microcontroller

Interfaces & Endpoints

  • • If 0: Mass Storage Bulk-Only (EP1 IN / EP2 OUT, 512B)
  • • If 1: HID Boot Mouse (EP3 IN, 8B, 1ms)
  • • If 2: HID Boot Keyboard (EP4 IN, 8B, 4ms)
  • • No Video Class (0x0E) — not a KVM video path

Protocol Channels

  • • HID Injection: 0xD9 CDB (types 3/4/6) over Bulk-Only
  • • File/Clipboard: UPipe (vendor CDB, magic TBD)
  • • ISO9660 payload: Windows SKLoader + macOS GoBridge
  • • Firmware: not dumped (internal peer routing unknown)
